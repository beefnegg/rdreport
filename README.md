# Dashboard Reksadana

Apps Script dashboard untuk menampilkan dan mengelola data portofolio reksadana langsung dari Google Spreadsheet. UI modern, responsif, dan langsung terbuka dari menu Spreadsheet.

## Fitur
- Ringkasan otomatis dari data aktif
- Tabel interaktif reksadana
- Modal detail per reksadana
- Format IDR penuh, tanggal Indonesia, persen sesuai format Sheets

## Setup
1. Buat Google Spreadsheet, atur header, lalu buka Script Editor.
2. Buat file `Code.gs` dan `index.html` sesuai yang ada di folder `apps-script`.
3. Simpan lalu buka menu **Reksadana Dashboard > Buka Dashboard Web**.
